# Café Finder

Find cafés near you or in any city. Shows them on a map and in a list
sorted by distance, with address, phone and Google Maps directions.

**Live demo:** https://berrouane-wafa.github.io/cafe-finder/

## Features
- Search by city or neighborhood, or use your location
- Radius and feature filters (takeaway, outdoor seating, Wi-Fi)
- Map and list synced: click a card or a marker
- Falls back across several Overpass servers when one is busy

## Built with
JavaScript, Leaflet, OpenStreetMap, Overpass API, Nominatim
